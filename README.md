# Reposter frontend

Личный кабинет администратора на React, TypeScript и SCSS Modules. Работает с API `reposter-backend` через защищённую cookie-сессию; токен администратора не хранится в браузере.

## Разработка

```sh
npm install
npm run dev
```

Vite проксирует `/v1` на `https://199.246.126.13.sslip.io`. Для локального бэкенда укажите `REPOSTER_API_TARGET=http://127.0.0.1:8080` при запуске. Пароль входа — `PANEL_PASSWORD` в `.env` бэкенда. Бэкенд должен поддерживать браузерный вход.

## Сборка и размещение

```sh
npm run build
```

Разместите `dist/` на том же домене, что и `/v1`, чтобы cookie-сессия и проверка Origin работали корректно. Продакшн `compose.prod.yaml` бэкенда монтирует `../reposter-frontend/dist` в Caddy. Подробности — в `reposter-backend/DEPLOYMENT.md`.

Панель использует дополнительные `GET /v1/routes` и `GET /v1/statistics` для связей и полной статистики. Пока бэкенд с этими маршрутами не обновлён, интерфейс работает с существующим API, но связи источников и полная статистика не отображаются. Статистика из последнего списка черновиков ограничена 100 записями.
